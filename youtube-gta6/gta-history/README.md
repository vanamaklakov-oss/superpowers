# «Как появилась GTA»: исторический ролик в стиле живописного комикса, 64 с
Стиль взят из TikTok storikon23 (картинки-иллюстрации, наезды камеры, субтитры по одному слову по центру, рубленая драматичная подача).
- Картинки: 14 штук из Grok Imagine (9:16), хвост стиля: «dramatic painterly comic illustration, bold ink lines, warm yellow-orange-red palette with deep shadows, cinematic lighting, vertical 9:16, no text, no logos». Сами картинки в репозиторий не кладём.
- `tts_all.py`: озвучка `lines.txt` (Дмитрий, +8%, −4Hz) через /home/user/bd/build.py. `make.py`: движение камеры (zoompan), субтитры по слову, своя музыка (гул, струнные, удары на склейках), сведение, зерно и виньетка.
Факты (Wikipedia, Grand Theft Auto (1997)): начало разработки 4.04.1995, DMA Design, Данди; рабочее название Race'n'Chase, игрок поначалу был полицейским; пиар Макса Клиффорда; дебаты в Палате лордов 20.05.1997; релиз на ПК 28.11.1997; 3,5 млн копий к октябрю 1999. Баг с агрессивной полицией не подтверждён, в ролике подан как «по легенде».
