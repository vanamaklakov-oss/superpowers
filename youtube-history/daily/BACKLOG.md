# Daily Shorts backlog (6 a day, no music, from material already received)

Each video: 5–6 sentences, ~30–40 s, one myth or one surprising fact, every date checked by web search
before narration (write the sources into script.py). Images come from an existing project's images/ folder.
Build: add the day's entries to make_day.py (new slugs, next number), `python3 make_day.py && ./run_day.sh`.
Rules: no background music (MUSIC=1 turns it back on), Russian, "Ютуб" not "YouTube", contested facts said as
"по одной из версий / по легенде", never use images flagged as copyrighted (modern signed art, Pinterest AI art).
