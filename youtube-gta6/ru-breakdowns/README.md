# 5 разборов на русском (стикерный стиль)
- `bd.ts`: движок стиля (в проекте anidoodle: `src/canvas-core/`). Фон из плывущих пятен, дудлы с эффектом покадровой анимации, стикеры с обводкой и цветной тенью, элементы выпрыгивают на нужном слове.
- `scripts.py`: сценарии 5 роликов (pc, 40sec, chrono, numbers, meme) с подсказками-словами для каждого элемента.
- `build.py tts|spec|post <video|all>`: озвучка (ru-RU-DmitryNeural, скорость +18% от базовой), разметка ролика, музыка, субтитры и сборка. Рендер между шагами spec и post: `node tools/render.mjs bd<video>`.
- Особенности edge-tts: случайные отказы. Сборщик перебирает небольшие сдвиги скорости и тона и озвучивает по одному предложению. «YouTube» латиницей не проходит, пишем «Ютуб».
- Проверка речи: faster-whisper. «ПК-версию» звучит неразборчиво, лучше «версию для ПК».
