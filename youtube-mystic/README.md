Две рубрики: **«Мистика»** (реальные загадки, только проверяемые факты, «по легенде», «очевидцы утверждают») и
**«Страшные истории»** (вымысел, сериал «Часть 1/2», выбор в конце).

## kv13 — «Квартира 13», часть 1 (вымысел), 71 с
Формат: экраны телефона (блокировка, чат подъезда, закреплённые правила) + плоские мультяшные персонажи, всё нарисовано
кодом (PIL), без чужих материалов. Голос ru-RU-DmitryNeural (+6%, +14Hz), субтитры по 2–3 слова, свой эмбиент, стук, пинги.
- `python3 tts.py` → `vo/NN.mp3` + тайминги слов (перегенерирует только изменённые фразы)
- `python3 build.py --stills` → `stills/NN.jpg` (быстрый просмотр кадров), `python3 build.py` → `kv13_part1.mp4`
- Озвучка проверена faster-whisper small (mp3 декодировать через ffmpeg → numpy: у PyAV несовместимая версия).

**Название:** `В 3:13 в чат подъезда пишет квартира, которой нет 😨 #shorts`
**Описание:** `В нашем доме нет 13-й квартиры. Но каждую ночь в 3:13 она пишет в чат подъезда… А ты бы открыл? 👇 Часть 1. История вымышлена.`
