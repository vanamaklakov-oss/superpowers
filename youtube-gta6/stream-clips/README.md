# TikTok live highlight cutter
`./rec.sh <channel>` records a TikTok LIVE (flv) in a 3 h loop; `python3 highlights.py file.mp4 N` cuts N vertical
captioned highlights (loudness jump + hype words + motion, whisper small, auto language).
Lives marked 18+/logged-in only (webcast status 4003110) cannot be recorded without an account.
Only publish clips with the streamer's permission.
