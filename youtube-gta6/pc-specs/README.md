# Can your PC run GTA 6? Neon breakdown (US), 47.5 s
Format taken from a Russian TikTok breakdown (PS5 specs as the benchmark). Remade with our own drawn icons and a synthwave backdrop: no game footage, no product photos.
Film: `pcspecs.ts` in the anidoodle project (`src/canvas-core/`), host `src/hosts/page-pcspecs.ts`; `node tools/render.mjs pcspecs`.
Narration: `lines.txt`, en-US-AndrewNeural +12%/+6Hz; voice offsets and cue frames in `timing.json`.
Notes: edge-tts sometimes returns no audio for certain sentences (for example ones starting with "Want ..."); rephrase them. Run every number through whisper: "Want 60" was heard as "160" and "For sixty" as "four sixty", so the line became "To hit sixty FPS".
Facts: PS5 specs are Sony's published figures (8-core Zen 2 up to 3.5 GHz, 10.28 TFLOPS, 16 GB GDDR6, 5.5 GB/s SSD). The PC equivalents are estimates, and no PC version is announced.
